# ShortLinkService

Консольный сервис создаёт короткие коды для HTTP- и HTTPS-ссылок. По коду можно открыть исходный адрес в браузере. У каждой ссылки свой лимит переходов и срок действия.

## Запуск

Понадобится JDK 26. Для открытия ссылок нужна графическая среда с браузером по умолчанию.

Выполните из корня проекта:

```sh
javac -encoding UTF-8 -d target/classes -sourcepath src/main/java src/main/java/org/example/Main.java
java -cp target/classes org.example.Main
```

В IntelliJ IDEA можно открыть проект, выбрать JDK 26 и запустить из корня проекта класс `org.example.Main`.

Ссылки и UUID пользователей хранятся в памяти. При выходе из приложения эти данные теряются.

## Настройки

Приложение читает `application.properties` из рабочего каталога при запуске. В IntelliJ IDEA укажите корень проекта в поле **Working directory**. После изменения настроек перезапустите приложение.

| Параметр | Исходное значение | Назначение |
| --- | --- | --- |
| `link.ttl.seconds` | `86400` | Срок действия ссылки в секундах. Для одного часа укажите `3600`. |
| `link.default-visit-limit` | `10` | Лимит переходов, если при создании нажать Enter. |
| `link.code-length` | `6` | Длина короткого кода от 1 до 64 символов. |
| `cleanup.interval.seconds` | `1` | Интервал фоновой проверки просроченных ссылок в секундах. |

Все параметры обязательны и принимают положительные целые числа. Если файл отсутствует или содержит ошибку, приложение выведет сообщение при запуске.

## Создание короткой ссылки

1. Введите полный адрес, например `https://example.org/articles/123`, и нажмите Enter.
2. Введите положительное целое число, например `3`, чтобы разрешить три перехода. Пустая строка устанавливает лимит из настроек (10 переходов по умолчанию).
3. Скопируйте выданную короткую ссылку, например `/aB3dE5`. При первом создании ссылки приложение также выдаст UUID и выберет этого пользователя как текущего.

Один и тот же исходный URL, сокращённый разными пользователями, получает разные короткие коды.

## Переход и управление ссылками

После запуска вводите по одной команде на строку.

| Команда | Действие |
| --- | --- |
| `go /aB3dE5` | Открывает исходный адрес в браузере и показывает число использованных переходов и лимит. Выбирать пользователя для перехода не требуется. |
| `edit /aB3dE5 5` | Устанавливает новый общий лимит в 5 переходов. Уже использованные переходы сохраняются. |
| `delete /aB3dE5` | Удаляет ссылку. |
| `user <UUID>` | Выбирает пользователя, созданного в текущем сеансе. Подставьте выданный UUID вместо `<UUID>`. |
| `user new` | Сбрасывает выбор пользователя. При создании следующей ссылки приложение выдаст новый UUID. |
| `exit` | Завершает работу приложения. |

Подставляйте свой код с учётом регистра. В командах `go`, `edit` и `delete` допустим код без начального `/`. Изменить лимит и удалить ссылку может только её создатель. Если вы переключились на другого пользователя, сначала выберите UUID создателя командой `user <UUID>`.

## Лимит переходов и срок действия

- Последний разрешённый переход открывает страницу, после чего консоль сообщает об исчерпании лимита. Следующие попытки блокируются. Пока ссылка действует, владелец может восстановить доступ, установив лимит выше числа уже использованных переходов.
- Если приложение не смогло открыть браузер, попытка не расходует лимит.
- Срок действия отсчитывается с момента создания и по умолчанию составляет 24 часа. По его истечении переходы блокируются, а фоновая очистка удаляет ссылку. При попытке открыть просроченную ссылку консоль выводит «Срок действия ссылки истёк. Создайте новую ссылку». После очистки сервис хранит только код ссылки до конца сеанса, чтобы продолжать показывать это сообщение. Для неизвестных и вручную удалённых кодов консоль выводит «Короткая ссылка не найдена». Чтобы снова получить короткую ссылку на тот же ресурс, повторите сокращение исходного URL.

## Тестирование

Из корня проекта выполните `mvn test` с JDK 26. Модульные тесты проверяют уникальность кодов, права владельца, лимиты и сроки жизни в час и сутки. Интеграционные тесты подают команды в консоль и проверяют её сообщения и адрес, переданный обработчику браузера. Для запуска тестов графическая среда не нужна.
